# qb-ladder
Sometimes you just need someone to agree with you. Rank quarterbacks and hear from an analyst exactly why you're right.

### Run Locally

Ensure your Google Gemini API key is set as an enviornment variable:
```bash
export GEMINI_API_KEY="..."
```

Build & run the containers:
```bash
docker compose up --build
```

View the app at http://localhost:3000
